# Chicken Dinner Timer

A cooking schedule app for roast chicken dinners. Enter the bird's weight and the time it goes in the oven, and get a minute-by-minute timeline covering everything from prep to gravy — including roast potatoes and Yorkshire puddings.

## Features

- Weight-based cooking time calculation (45 min per kg + 20 min)
- Step-by-step timeline from prep through to serving
- Covers the full Sunday roast: chicken, roast potatoes, vegetables, Yorkshire puddings, gravy
- Configurable oven start time

## Tech Stack

- Svelte 3, TypeScript, Vite 3
- bonsai.css for base styles

## Getting Started

```bash
npm install
npm run dev
```
